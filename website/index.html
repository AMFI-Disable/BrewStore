Homebrew, in a focused macOS app.

Browse casks and formulae, inspect updates, manage services and taps, and preview application removal before anything changes.

This zero-budget build is ad-hoc signed and is not notarized by Apple. Read the installation notes before opening it.

Apps

Search and manage Homebrew casks with installed and update state.

Formulae

Services

Inspect and control Homebrew-managed background services.

Safe removal

Preview application support files before selected items are moved to the Trash.

Install on macOS

  1. Download the DMG and compare its SHA-256 checksum with the published checksum.
  2. Open the DMG and drag BrewStore.app to Applications.
  3. If macOS blocks the app, use System Settings → Privacy & Security → Open Anyway.
  4. Only if you trust the verified download, use the quarantine-removal command below.
xattr -d com.apple.quarantine ~/Downloads/brewstore-1.0.0.dmg

Removing quarantine does not make the app signed or notarized. Never disable Gatekeeper globally.
