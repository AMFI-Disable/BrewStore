BrewStore 1.0.0 · Complete Mac App Manager

The complete package & app manager for macOS.

Unifying Homebrew, Mac App Store apps, per-app cache cleaning, Apple Silicon native migration, macOS launch daemons, and 1-command Mac Blueprint backups in an Apple Design Award-caliber interface.

Get BrewStore Releases GitHub Repository
🏬

Unified Dual-Store App Manager

Unify Homebrew Casks, CLI tools, Mac App Store apps, and external unmanaged apps in one clean catalog. Automatically recommends Homebrew for faster updates and zero Apple ID prompts.

🧹

Per-App Storage & Cache Cleaner

Visual 3-column disk breakdown: Binary Size vs Caches vs Application Data. Dedicated Clean Caches button safely moves GBs of cache to ~/.Trash while preserving logins and user settings.

🍎

Apple Silicon vs Rosetta 2 Inspector

Identifies legacy Intel apps draining battery under Rosetta 2 emulation. Color-coded architecture badges (ARM64, Universal, Rosetta 2) with 1-click migration to native Apple Silicon.

⚙️

Login Items & Background Daemons

Combines Homebrew services with macOS user/system LaunchAgents (~/Library/LaunchAgents) and Login Items. Inspect live CPU, RAM RSS, and listening ports with instant enable/disable toggles.

🚀

1-Command Mac Blueprint & Restore

Capture your entire machine state into a portable Mac Blueprint including Homebrew packages, taps, Mac App Store apps, pinned versions, and preferences. Restore on any new Mac in 1 command.

🛡️

CVE Vulnerability Scanner

Automated security auditing with brew audit and CVE advisory engine. Computes a 0–100 Security Hardening score with 1-click patch upgrades.

📌

Version Pinning & Switcher

Lock sensitive developer toolchains against breaking updates via brew pin and seamlessly switch between historical Cellar versions in 1 click.

⚡️

Mirror Speed Benchmark

Real-time HTTP HEAD latency benchmarking across Fastly, USTC, Tsinghua TUNA, and Aliyun with 1-click shell configuration.

⌘

Command Palette (⌘K)

Lightning-fast global launcher with power verbs (> upgrade all, > cleanup, > doctor, > benchmark) and instant fuzzy search across 6,000+ packages.
