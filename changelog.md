# Changelog

## 1.0.0

Initial focused BrewStore product extraction.

- Homebrew cask and formula browsing.
- Installed and outdated package state.
- Package install, upgrade, and uninstall actions.
- Homebrew service controls.
- Homebrew tap management.
- Preview-first removal flow for Homebrew-installed applications.
- Shared JuicerKit command and removal safety foundations.

Deferred from this release:

- Brewfile synchronization.
- Store analytics and popularity charts.
- Telemetry and remote accounts.
